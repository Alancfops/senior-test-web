# Registro de Software — Sênior Teste Funcional (STF)

---

## Documento 1 — STF Mobile (aplicativo + API)

### O que o software faz

Aplicativo para fisioterapeutas acompanharem pacientes idosos por meio de testes funcionais padronizados. Com ele, o fisioterapeuta cadastra pacientes, aplica as avaliações funcionais, consulta o histórico e a evolução de cada paciente e gera relatórios em PDF. Inclui o servidor (API), que armazena os dados, calcula os resultados das avaliações, gera os relatórios e controla o acesso dos usuários.

### Linguagem de programação

- **TypeScript**
- **SQL** (banco de dados PostgreSQL)

## Documento 2 — STF Gerenciador Web (painel administrativo)

### O que o software faz

Painel web para o administrador supervisionar o uso da plataforma STF. Permite visualizar os fisioterapeutas e seus pacientes, transferir pacientes entre fisioterapeutas, excluir registros, consultar as avaliações e os gráficos de evolução, baixar relatórios em PDF e acompanhar o log de auditoria das ações realizadas.

### Linguagem de programação

- **TypeScript**

### Data de início

**25/08/2026** — primeira sessão de desenvolvimento registrada.
